INCOBES / ESPACIO DE MIEMBROS

Un espacio privado para colaborar.

El espacio de miembros permite a integrantes autorizados mantener su perfil, consultar el directorio y colaborar dentro de INCOBES.

01 / FUNCIONES

Qué permite hacer

El portal privado reúne perfiles, capacidades, intercambios, propuestas y solicitudes de colaboración. Cada persona gestiona los datos de su perfil y decide si algunos datos de contacto se comparten con integrantes activos.

Una persona puede enviar una foto de perfil o el logotipo institucional. Administración revisa los archivos; si los aprueba, sólo se muestran en el directorio interno. No se publican automáticamente en la web abierta.

02 / GOOGLE DRIVE

Uso de datos de Google

La conexión con Google Drive la autoriza una persona administradora con la cuenta incobes@gmail.com. La aplicación solicita identidad y correo para confirmar esa cuenta, y el permiso drive.file para crear y usar las carpetas y archivos vinculados a las cargas del portal.

La aplicación no solicita acceso general a todo el Drive ni usa datos de Google para anuncios, venta de datos o entrenamiento de modelos. Los integrantes no conectan sus propias cuentas de Google para subir fotos.
